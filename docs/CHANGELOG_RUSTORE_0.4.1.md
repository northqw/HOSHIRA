# Hoshira 0.4.1 (406)

Текст для RuStore относительно версии 0.4.0 (402):

> Что нового:
>
> - Ускорили запуск, загрузку разделов и повторное открытие страниц благодаря локальному кэшу.
> - Исправили массовые пропуски обложек: добавили резервный источник и сохранили хорошее качество изображений.
> - Каталог теперь автоматически подгружает новые карточки при прокрутке.
> - Приложение запоминает положение экранов при переходах между разделами и карточками релизов.
> - На странице поиска появились недавно открытые результаты.
> - Улучшили видеоплеер: снизили расход памяти, добавили медиакэш и надёжное восстановление источника при сетевых ошибках.
> - Исправили навигацию пультом на телевизорах, включая переход с таймлайна к кнопкам смены серии.
> - Переработали главную страницу телевизора: hero-блок больше не мешает просмотру рядов карточек.
> - Улучшили работу со списками аккаунта, избранным и продолжением просмотра.
> - Исправили ряд ошибок и повысили общую стабильность приложения.
