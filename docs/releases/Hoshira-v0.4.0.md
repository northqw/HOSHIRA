# Hoshira v0.4.0 — Native HLS

Hoshira 0.4.0 переводит воспроизведение HLS на нативные плееры Windows и Android
и доводит мобильный просмотр до стабильного полноэкранного сценария.

## Основные изменения

- нативное HLS-воспроизведение на Android через Media3 и на Windows через JavaFX;
- исправлены зависания, краткие пропадания звука и повреждение кадра;
- исправлено воспроизведение CVH и переключение качества потока;
- исправлены лоадер, смена эпизодов, пропорции видео и мобильные элементы управления;
- добавлен автоматический повтор загрузки обложек;
- обновлены иконки навигации и фирменная иконка Hoshira, включая тематическую
  монохромную иконку Android;
- синхронизированы версии Android-приложения, Windows portable и установщика.

## Артефакты

- `Hoshira-Android-0.4.0-release.apk`;
- `Hoshira-0.4.0-Windows-portable.zip`;
- `Hoshira-0.4.0-Setup.exe`.
