# Hoshira Desktop v0.2.6 — Public Beta

Hoshira Desktop v0.2.6 — крупное обновление публичной бета-версии. Основное
внимание уделено встроенному плееру, отзывчивости интерфейса, обновлению
главной страницы и подготовке экспериментальной версии для Linux.

## Главное

- Полностью переработан встроенный плеер с единым минималистичным интерфейсом
  для Alloha и Kodik.
- Добавлены собственные элементы управления: воспроизведение, перемотка,
  громкость, выбор качества, переключение источника и полноэкранный режим.
- Исправлен вход и выход из полноэкранного режима, включая клавишу Escape.
- Alloha теперь автоматически выбирается первым, если он доступен для
  выбранной озвучки. Переключение на Kodik вручную остаётся доступным.
- Для Kodik добавлена фильтрация рекламных запросов и понятное объяснение
  возможной задержки запуска. Экран загрузки скрывается не позднее чем через
  6 секунд.
- При переключении серии или источника внутри открытого плеера повторно
  используется уже созданный браузерный host.

## Интерфейс

- Montserrat стал основным шрифтом во всём приложении, включая название
  Hoshira, навигацию, карточки и плеер.
- Обновлена верхняя навигация: увеличены пункты «Главная» и «Каталог»,
  удалена кнопка поддержки, а поиск теперь разворачивается из компактной
  иконки.
- Закрытие поиска возвращает пользователя на экран, где поиск был открыт,
  вместо автоматического перехода в каталог.
- Переработаны выпадающие списки: добавлены аккуратные векторные стрелки,
  а меню получили скругления и обводку в стиле приложения.
- Исправлен цвет и внешний вид иконки «В любимое».
- Обновлены скриншоты продукта в русской и английской версиях README.

## Главная страница и контент

- Блок «Откройте что-то новое» теперь использует поле `recommends` API.
  Прежняя подборка применяется только как резервный вариант.
- «Свежий релиз» и «Последние обновления» обновляются в фоне каждые
  10 минут — перезапуск приложения больше не требуется.
- Фоновое обновление сохраняет уже загруженный контент при временной ошибке
  сети.

## Производительность и стабильность

- Устранён сброс состояния приложения при открытии плеера и переключении
  полноэкранного режима.
- Сокращена минимальная продолжительность стартового экрана и ускорен поиск.
- Оптимизирована загрузка изображений в карточках.
- Плеер больше не обходит всё DOM-дерево источника на каждом цикле проверки:
  доступные корни кэшируются, а поиск качества выполняется по требованию.
- WebView2 перехватывает только потенциально рекламные адреса, а не каждый
  ресурс страницы и сегмент видео.
- Удалена зависающая плашка «Ожидание видео от источника…» и добавлен
  безопасный тайм-аут загрузочного экрана.
- Расширены автоматические тесты навигации, фонового обновления, выбора
  источника и интеграции плеера.

## Установщик Windows

- Версия приложения и фирменного установщика синхронизирована до 0.2.6.
- Установщик получил русскую оболочку Hoshira, собственную иконку и создание
  ярлыка.
- Перед установкой проверяется Microsoft Edge WebView2 Runtime. Если Runtime
  отсутствует, запускается официальный bootstrapper Microsoft.
- Поддерживается обновление поверх предыдущей установленной версии.

## Экспериментальная поддержка Linux

- Добавлена сборка пакетов DEB и RPM через CI.
- Реализован Linux-host плеера на WebKitGTK и GStreamer.
- Добавлено хранение данных аккаунта с учётом платформы.
- Улучшено отслеживание движения мыши и отображение элементов управления
  поверх плеера.

Linux-версия остаётся экспериментальной: воспроизведение зависит от
установленных в системе WebKitGTK, GStreamer и мультимедийных кодеков.

## Установка на Windows

1. Скачайте `Hoshira-0.2.6-Setup.exe`.
2. Запустите установщик и выберите папку установки.
3. После завершения откройте Hoshira через созданный ярлык.

Требования: Windows 10/11 x64 и подключение к интернету. Установщик пока не
подписан коммерческим сертификатом, поэтому Microsoft Defender SmartScreen
может запросить дополнительное подтверждение запуска.
