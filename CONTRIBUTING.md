# Участие в проекте Hoshira

Спасибо за интерес к Hoshira.

Hoshira — проприетарный проект с моделью **All Rights Reserved**. На текущем
этапе проект не принимает внешние изменения исходного кода и запросы на
слияние. Публикация исходников не предоставляет разрешения создавать или
распространять изменённые версии приложения.

## Что можно предложить

- сообщить о воспроизводимой ошибке;
- предложить улучшение интерфейса или пользовательского сценария;
- описать проблему совместимости;
- указать на неточность в публичной документации;
- отправить приватный отчёт об уязвимости по правилам из
  [SECURITY.md](SECURITY.md).

Перед созданием задачи проверьте, не обсуждалась ли проблема ранее. Хороший
отчёт содержит:

- версию Hoshira и версию Windows;
- понятные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- обезличенные журналы или снимки экрана, если они действительно необходимы.

Не публикуйте пароли, токены, персональные данные, ссылки на приватные медиапотоки
и технические детали необъявленных уязвимостей.

## Запросы на слияние

Незапрошенные запросы на слияние могут быть закрыты без рассмотрения. Если
владелец проекта отдельно пригласит вас подготовить изменение, условия передачи
прав и порядок работы будут согласованы письменно до начала разработки.

Отправка идеи или отчёта об ошибке не передаёт право собственности на
существующий код Hoshira и не изменяет условия файла [LICENSE](LICENSE).

## Сроки ответа

Hoshira развивается одним владельцем. Фиксированный SLA не предоставляется, но
корректно оформленные сообщения рассматриваются по мере возможности и с учётом
влияния проблемы на пользователей.

# Contributing to Hoshira

Thank you for your interest in Hoshira.

Hoshira is proprietary **All Rights Reserved** software. External source-code
contributions and pull requests are not currently accepted. Public source
availability does not grant permission to create or distribute modified builds.

You are welcome to report reproducible bugs, suggest product improvements,
describe compatibility issues, or point out inaccuracies in public
documentation. Security vulnerabilities must be reported privately according
to [SECURITY.md](SECURITY.md).

Do not publish passwords, tokens, personal information, private media URLs, or
details of undisclosed vulnerabilities. Unsolicited pull requests may be closed
without review. Any invited code contribution will require written terms agreed
with the project owner before development begins.

There is no guaranteed response SLA. Reports are reviewed as availability and
user impact permit.
